# Historical material

This directory preserves earlier Julia implementations, DTLZ5(2,3) work,
original README files and package metadata. It is not the current execution
entry point. Historical source and documentation may refer to former paths,
imports and numerical protocols; their presence does not establish that they
run against the current package without adaptation.

Use the root README, `src/orca/`, `experiments/` and `examples/` for current
workflows. The original metadata is retained for provenance, including the
unresolved author/email inconsistency described in `docs/known_issues.md`.
